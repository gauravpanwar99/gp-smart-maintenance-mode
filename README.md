# 🛠 GP Smart Maintenance Mode

GP Smart Maintenance Mode is a lightweight and flexible WordPress plugin that allows site owners to:

✅ Enable maintenance mode instantly  
✅ Display **custom HTML content** during maintenance  
✅ Track visitor access while maintenance mode is active  

Designed for developers, agencies, and site administrators who need more control than default maintenance pages.

---

## 🚀 Features

- 🔒 One-click maintenance mode enable/disable
- 🎨 Fully **custom HTML support** (no design limitations)
- 👀 **Visitor tracking** during maintenance mode
- ⚡ Lightweight & performance-friendly
- 🔧 Simple configuration via WordPress admin

---

## 🧠 Use Cases

- Website updates & deployments
- Server or database maintenance
- Landing page preview before launch
- Temporary access control during development

---

## 🏗 How It Works (High-Level)

1. Plugin intercepts frontend requests when maintenance mode is enabled
2. Custom HTML is served instead of theme output
3. Visitor data (IP, time, user agent) is logged for insights
4. Admin dashboard controls everything

---

## 📦 Installation

1. Download or clone the repository
2. Upload to `/wp-content/plugins/gp-smart-maintenance-mode`
3. Activate from **WordPress Admin → Plugins**
4. Configure settings from the plugin dashboard
